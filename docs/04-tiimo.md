# 04. Tiimo（Timo）— 認知負荷を下げる「視覚的プランナー」

> 観察対象: `tiimoapp.com`, `tiimoapp.com/product/to-do-list`, `webapp.tiimoapp.com/sign-in`
> Evidence: `ev_bdba93f4…`, `ev_8e44f8e9…`, `ev_edda4130…`, `ev_6c19b3fb…`
>
> **注**: ユーザー指定の「Timo」は、公式表記 **Tiimo**（`tiimoapp.com`）と同定した。
> ADHD / 自閉症などニューロダイバージェント向けの視覚的プランナー。

---

## 1. プロダクトの位置づけ

Tiimoは「効率化」ではなく **「認知負荷の削減」** を目的にしたプランナー。
時間をブロックで見せ、絵文字で意味づけし、完了を穏やかに示す。
UIの中心はタスクではなく **「1日の流れ（routine）」**。

`[OBS]` ヒーローは "A visual AI planner built for real life."、上に "App of the Year 2025"。
`[OBS]` ナビは `About us / Features / Resources / Timers / Log in / Try Tiimo for free`。
「Tasks」ではなく **「Timers」** がトップレベルにあるのが特徴。

## 3. デザイントークン（実測）

### 3.1 タイポグラフィ

| 役割 | 値 | 備考 |
|---|---|---|
| H1 | **56px / 400 / 61.6px** | Recoleta Regular |
| H2 | 49px / 400 | Recoleta |
| H3 | 28px / 400 | Recoleta |
| Body | 14–16.8px / 400 | SF Pro Text |
| Intro | 18px / 400 | |
| Font | `Recoleta Regular`, `Recoleta Medium`, `SF Pro Text` | |

**特徴**: 見出しは **400のみ**。太字を使わない。階層は**サイズと色**だけで作る。
`[INF]` 太字による「主張」を避け、穏やかなトーンを作っている。

### 3.2 カラー

| トークン | 値 | 用途 |
|---|---|---|
| `--tiimo-beige` | `#FCFCFC` | ページ背景 |
| `--tiimo-black` | `#161212` | 本文・CTA |
| `--heading` | `#161613` | 見出し |
| `--paragraphs` | `#161613BF` | 本文（75%不透明） |
| `--link` | `#9F85FF` | リンク・アクセント |
| `--tiimo-purple` | `#BCAAFF` | ヒーロー背景 |
| `--tiimo-purple-light` | `#E2DAFF` | タスク面 |
| `--tiimo-blue-primary` | `#C3CEFF` | タスク面 |
| `--tiimo-blue-secondary` | `#E7EBFF` | タスク面 |
| `--tiimo-pink` | `#FFB2DA` | アクセント |
| `--tiimo-pink-secondary` | `#FFE0F0` | タスク面 |
| `--tiimo-orange` | `#FF7E49` | 警告・強調 |
| `--tiimo-green-secondary` | `#7F9A7A` | 完了 |
| `--border` | `#16161321` | 12%の黒 |

**特徴**: **黒は純黒ではなく `#161212`**（わずかに赤み）。背景は `#FCFCFC`（純白ではない）。
パステルは4系統（紫・青・ピンク・緑）で、**同じ色相の中に2段階**（strong / secondary）を持つ。

### 3.3 角丸・影・余白

- radius: **16px**（カード）、120px / 140px（ピル）、8px（入力）、50%（アバター）
- shadow: `0 2px 5px rgba(0,0,0,.20)` のみ。**影は1種類**。
- gap: **24px**（最多）、10px、80px（セクション間）。カード間は10–12pxと狭い。
- セクション間は80px。**カードは密に、セクションは広く**。

## 5. インタラクション

| 操作 | 挙動 | 根拠 |
|---|---|---|
| タスク完了 | 円形リングが塗られ、紙吹雪/星が舞う | `[PROD]` 画像の装飾 + `[INF]` |
| 週/日切替 | セリフの `Week ▾` で切替 | `[OBS]` |
| フォーカス開始 | フローティングカードが出現、円形プログレスが進む | `[PROD]` |
| 優先度折りたたみ | `HIGH (3) ▾` でセクションを閉じる | `[INF]` |
| リスト切替 | セリフタブで `School / Groceries…` | `[PROD]` |
| AI入力 | 音声/テキスト → タスクに分解 | `[PROD]` `ai-prompt.png` |
| 気分記録 | スライダーで感情を記録 | `[PROD]` `mood-neutral.png` |

モーションは**穏やか**。`[INF]` 200–300ms、ease-out、バウンスは弱め。完了時だけ紙吹雪。

## 6. このUIの強み

1. **時間が「箱」で見える**。文字のリストではなく、高さを持つブロック。1日の密度が一目でわかる。
2. **絵文字が記憶のフック**。`🧺 Laundry` `🧘 Morning routine`。テキストより速く認識できる。
3. **書体が感情を作る**。Recoletaのセリフが「事務的でない」印象を与える。ADHD向けの心理的安全性。
4. **完了が穏やか**。赤いバツや「遅延」ではなく、リングが静かに閉じる。
5. **プラットフォームをまたぐ一貫性**。iPhone / Watch / Web で同じカード、同じ色、同じセリフ。

## 7. 弱点・真似しない方がいい点

- **情報密度が低い**。1画面に3–5タスク。大量のタスクには向かない。
- **色がパステルなのでコントラストが弱い**。`#161613BF` の本文は背景によっては読みづらい。
- **絵文字依存**。OSによって絵文字の見た目が変わる。ブランドの一貫性が崩れる。
- **セリフ体は長文に不向き**。見出しだけに限定する必要がある。
- **「かわいい」が業務ツールでは浮く**。チーム利用にはトーンの調整が必要。

## 8. 盗むべきもの

| 原則 | 移植方法 |
|---|---|
| 時間を箱で見せる | リストだけでなく、高さを持つタイムブロックを併設 |
| 絵文字をアイコンに | タグごとに絵文字を1つ。画像アセット不要で記憶に残る |
| セリフの見出し | 見出しだけRecoleta系。本文はサンセリフで可読性を確保 |
| 完了は静かに | バツや赤ではなく、リングが閉じる / 塗りつぶし |
| 余白を恐れない | セクション間80px、カード間10pxのメリハリ |
| 非難しないコピー | 「遅れています」ではなく「次の空きは15:30です」 |
