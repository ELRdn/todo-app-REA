# 05. Structured — 1日を「連続した時間」にするUI

> 観察対象: `structured.app`, `web.structured.app/auth/login`
> Evidence: `ev_47e42d9b…`, `ev_496f8dfa…`, `ev_3f193ca9…`

---

## 1. プロダクトの位置づけ

Structuredは、**1日の予定を縦のタイムラインに並べる**デイリープランナー。
タスクリストとカレンダーの間ではなく、「今日という1本の線」を編集する感覚に振り切っている。

`[OBS]` コピーは "the day planner app that everyone is using" / "one planner, one timeline, 99 appointments"。
`[OBS]` ナビは `features / reviews / team / support / blog / research / Structured Web`。
「Tasks」ではなく **「Timeline」** がプロダクトの中心語。

## 2. 画面の解剖

### 2.1 マーケティング・トップ（`evidence/structured/screenshots/00.png`）

```
┌──────────────────────────────────────────────────────────────┐

│  ╭──────────────────────────────────────────────────────╮   │
│  │ ✓ Structured  features reviews team support blog …  [Start planning] │ 黒ピル
│  ╰──────────────────────────────────────────────────────╯   │
│                                                              │
│                    （動画の上に薄い暗幕）                      │

```

- **ヒーローはフルスクリーン動画**（カフェでノートPCを開く人物）。テキストは最小限。
- **浮遊する黒いピルナビ**。角丸は完全なピル、背景は半透明の黒、白文字。
- 動画の上に**黒い半透明のオーバーレイ**を敷き、ナビの可読性を確保。
- `[INF]` 動画は「理想の1日」を感情で伝え、プロダクトの説明はスクロール後に置く。

### 2.2 ヒーロー下（`evidence/structured/screenshots/01.png` 〜）

- 背景は**コーラル `#FFA7A0`**。その上に白いテキスト。
- 見出しは **78px / Inter 400 / -1.5px**。2行目は 300 / -4px。
- すぐ下に**アプリの巨大なスクリーンショット**（2402×10672 のタイムライン）。
  `[INF]` 1枚の画像で「1日の全体像」を見せる。スクロールそのものがタイムライン体験。

### 2.3 機能セクション

- `visual planning` / `import calendars` / `plan with AI` の3つ。
- 各機能は**円形のパステルブロブ**にアイコンを載せた画像。
- 見出しは 64.08px / 300 / -1.5px。本文は16px。
- `[OBS]` 機能名はすべて小文字（`visual planning`）。`[INF]` 威圧感を消すため。

## 3. デザイントークン（実測）

### 3.1 タイポグラフィ

| 役割 | 値 | 備考 |
|---|---|---|
| Display | **78px / 400 / 81.9px / -1.5px** | Inter |
| Display alt | 78px / 300 / -4px | 2行目 |
| H3 | **64.08px / 300 / 64.08px / -1.5px** | 機能見出し |
| H4 | 30px / 400 | |
| Body | 16px / 400 / 24px | 359要素 |
| Small | 12px / 400 | |
| Button | 18–20px / 400–500 | |
| Font | `Inter, "Inter Fallback", system-ui, sans-serif` | 300/400/500/600/700 |

**特徴**: 見出しは **300（Light）**。Trackingは **-1.5〜-4px** と非常に詰める。
「大きく、軽く、詰める」で、モダンで建築的な印象。本文は16pxでニュートラル。

### 3.2 カラー

| トークン | 値 | 用途 |
|---|---|---|
| hero | `#FFA7A0` | コーラル（ hero / CTA / 今日） |
| primary blue | `#5C85A8` | CTA・リンク |
| blue 2 | `#6185A8` | |
| deep blue | `#2C5073` | テキスト |
| dark | `#1C1C1E` | ログイン背景 |
| ink | `#000000` / `#FFFFFF` | |
| task colors | コーラル / 青 / グレー / ワイン / 緑 | カテゴリ |

**特徴**: **コーラルとブルーの2色**がブランド。タスクのカテゴリ色は写真から抽出したような
低彩度の色（`#F98E87`, `#4A7FA5`, `#7C9A5B`, `#7D2E45`）で、**画面全体が絵本のように見える**。

### 3.3 角丸・影・余白

- radius: **完全ピル**（`9999px`）、4px（タブ）、40px（大ボタン）、20px（カード）
- shadow: ほぼなし。写真と色面で境界を作る。
- gap: 8px（最多）、12px、32px、40px
- セクション間は非常に広い（数百px）。**スクロールのテンポがゆっくり**。

## 6. このUIの強み

1. **タイムラインがホーム**。リストやカンバンではなく、時間軸そのものが最初の画面。
2. **「空き時間」を提案に変える**。`30min of free time?`。空白を不安ではなくチャンスにする。
3. **日付の表現が強い**。`16. October 2025`。数字と月名の組み合わせで、カレンダーアプリより日記に近い。
4. **色がカテゴリ**。コーラル/青/ワイン/緑。タイムラインのブロックが色で記憶される。
5. **書体のコントラスト**。Inter 300の巨大見出しと16px本文。**同じフォントでここまで差が出る**好例。

## 7. 弱点・真似しない方がいい点

- **動画ヒーローは重い**。LCPが悪化する。モバイル回線ではつらい。
- **情報密度が低い**。1画面に5–8タスク。大量のタスク管理には向かない。
- **色のコントラスト**。パステル背景に白文字の箇所があり、WCAG AAを満たさない可能性（推論）。
- **「1日」に最適化**。長期プロジェクト、依存関係、チームには向かない。
- **スクロールが長い**（18,168px）。マーケティングとしては没入感があるが、情報探索には不向き。

## 8. 盗むべきもの

| 原則 | 移植方法 |
|---|---|
| タイムラインをホームに | 起動直後に「今日の縦線」を表示。リストはタブで |
| 空き時間を提案 | `15:30–16:00 空いています。散歩は？` をカードで |
| 日付を大きく | `10月25日` を画面上部に48pxで。年はアクセント色 |
| カテゴリ色を低彩度に | パステルではなく、絵本のような落ち着いた色 |
| 巨大で軽い見出し | Inter 300 / 64–78px / tracking -2% |
| ピルボタン | CTAは完全ピル、角丸4pxのタブと使い分け |
